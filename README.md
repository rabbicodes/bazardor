# 🛒 বাজার দর (Bazar Dor)

## Description

Bazar Dor is a web application that helps users explore market categories and market-related information through a simple and user-friendly interface.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* HeroUI
* Better Auth
* MongoDB
* REST API
* DaisyUI
* React Icons
* React Hot Toast

## Features

1. Responsive design for mobile, tablet, and desktop.
2. User registration and sign-in.
3. Google and GitHub social login.
4. Category-based navigation.
5. Dynamic category pages.
6. Sorting options from low to high and high to low.
7. Bengali interface and localized dates.
8. Toast notifications for success and error messages.
9. Modern UI with Tailwind CSS and HeroUI.
10. Secure authentication using Better Auth.
